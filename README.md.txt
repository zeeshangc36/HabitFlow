# HabitFlow — Habit Tracker App

A modern, interactive habit tracker built with **HTML, CSS, and Vanilla JavaScript**, featuring weekly streak tracking, dynamic stats, and persistent storage using LocalStorage.

---

##  Live Demo

https://github.com/zeeshangc36/HabitFlow.git

---

## 📦 How to Run Locally

### Option 1 (Easiest)
1. Download or clone the repository
2. Open the project folder
3. Double-click `index.html`
4. The app will run directly in your browser

---

### Option 2 (Recommended: Local Server)

#### Using VS Code Live Server
- Install **Live Server extension**
- Right-click `index.html`
- Click **“Open with Live Server”**

---

## Tech Stack

- HTML5  
- CSS3 (Responsive UI + Grid Layouts)  
- Vanilla JavaScript (ES6+)  
- LocalStorage API (data persistence)  


## Features

- Weekly habit tracking grid  
- Streak calculation system  
- Dynamic completion stats  
- Add / edit / delete habits  
- Icon selection system with library  
- Week navigation (previous / next / current)  
- Fully responsive design  
- Persistent data (no backend required)  


## Project Structure

- index.html
- style.css
- script.js
- README.md
- ANSWERS.md

## Notes

- No installation or build tools required  
- Works fully offline once loaded  
- Data is stored in browser LocalStorage
